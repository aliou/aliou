## Pi Extensions

- [@aliou/pi-guardrails](https://github.com/aliou/pi-guardrails) ([npm](https://www.npmjs.com/package/@aliou/pi-guardrails)) — Security hooks to prevent destructive actions and secret-file access.
- [@aliou/pi-processes](https://github.com/aliou/pi-processes) ([npm](https://www.npmjs.com/package/@aliou/pi-processes)) — Background process management for Pi. Start long-running commands without blocking the conversation.
- [@aliou/pi-synthetic](https://github.com/aliou/pi-synthetic) ([npm](https://www.npmjs.com/package/@aliou/pi-synthetic)) — Provider for Synthetic, giving Pi access to open-source models via an OpenAI-compatible API.
- [@aliou/pi-ts-aperture](https://github.com/aliou/pi-ts-aperture) ([npm](https://www.npmjs.com/package/@aliou/pi-ts-aperture)) — Route Pi LLM providers through Tailscale Aperture.
- [@aliou/pi-toolchain](https://github.com/aliou/pi-toolchain) ([npm](https://www.npmjs.com/package/@aliou/pi-toolchain)) — Opinionated toolchain enforcement. Transparently rewrites commands to use preferred tools.
- [@aliou/pi-linkup](https://github.com/aliou/pi-linkup) ([npm](https://www.npmjs.com/package/@aliou/pi-linkup)) — Web search, answer, and content fetching via the Linkup API.
- [@aliou/pi-dev-kit](https://github.com/aliou/pi-dev-kit) ([npm](https://www.npmjs.com/package/@aliou/pi-dev-kit)) — Tools and commands for developing and updating Pi extensions.
- [@aliou/pi-playdate](https://github.com/aliou/pi-playdate) — Develop Playdate games in Lua and C. Build, run, inspect, and deploy games from Pi.
- [@aliou/pi-linear](https://github.com/aliou/pi-linear) — Pi extension for Linear: manage issues, projects, and teams directly from your coding sessions.
